# Acme Support Website

A professional customer support website built using HTML and CSS.

This project demonstrates how to create an accessible contact form using semantic HTML, proper form controls, labels, validation attributes, and structured page layouts. The website includes a Home page, Help Center, Contact Form, and a Thank You page for successful form submissions.

---

## Features

- Multi-Page Website
- Home Page
- Help Center Page
- Contact Form Page
- Thank You Confirmation Page
- Semantic HTML Structure
- Responsive Design
- Accessible Form Controls
- Browser Validation Support
- Professional Navigation Menu
- Clean and Modern User Interface

---

## Pages

### Home

The landing page introducing Acme Support and its services. It includes feature cards and navigation to support resources.

### Help Center

Provides guidance on how to complete the contact form and answers common customer questions.

### Contact

Allows users to submit support requests using a structured and accessible form.

### Thank You

Displays a confirmation message after the form has been successfully submitted.

---

## Form Features

The contact form includes:

- Full Name (Required)
- Email Address (Required)
- Subject Selection
- Message Field with Minimum Length Validation
- "How did you hear about us?" Radio Button Group
- Newsletter Subscription Checkbox
- Submit Button

---

## Accessibility Features

- Proper `<label>` and `for` associations
- Required field validation
- Semantic `<fieldset>` and `<legend>` usage
- Accessible form controls
